# سياسة الأرقام وأسلوب الكتابة — Numbers & Style Guide

يوضّح هذا الدليل قواعد كتابة الأرقام والمعرّفات والكلمات المفتاحية وتنسيق الشيفرة في لغة **لسان (Lisan 1.0.0+)**.

## 1. الأرقام والفاصلة العشرية

يدعم المحلل المعجمي (`src/lexer.rs`) كافة أنظمة الأرقام المستخدمة في العالم العربي والعالمي بشكل موحّد:

* **الأرقام الغربية (اللاتينية):** `0` إلى `9`
* **الأرقام العربية المشرقية:** `٠` إلى `٩`
* **الأرقام الفارسية / الأوردية:** `۰` إلى `۹`
* **الفاصلة العشرية:** النقطة (`.`) أو الفاصلة العشرية العربية (`٫`)
* **الترميز العلمي:** يدعم الصيغة العلمية مثل `1e3` أو `2.5e-4` أو `١٫٥e٣` مع فحص تجاوز النطاق لمنع `Infinity` و`NaN`.

### أمثلة صالحة
```lisan
دع سعر = 49.95
دع كمية = ١٢
دع ضريبة = ٠٫١٥
دع إجمالي = سعر * كمية * (1 + ضريبة)
اطبع(إجمالي)
```

> **توصية أسلوبية:** يُفضّل توحيد نمط الأرقام داخل المشروع الواحد (غربية أو عربية) لتسهيل القراءة والمراجعة الجماعية.

## 2. تطبيع الكلمات المفتاحية العربية

لتسهيل الكتابة دون أخطاء إملائية متكررة، يطبّع المحلل المعجمي الكلمات المفتاحية العربية تلقائياً:
* توحيد الهمزات: `أ` / `إ` / `آ` ← `ا` (مثلاً `إذا` و`اذا`، `أرجع` و`ارجع`).
* توحيد التاء المربوطة والهاء: `ة` ← `ه` (مثلاً `دالة` و`داله`، `حالة` و`حاله`).
* توحيد الألف المقصورة والياء: `ى` ← `ي`.
* تجاهل التشكيل والتطويل (`ـ`) داخل الكلمات المفتاحية.

## 3. المعرّفات (أسماء المتغيرات والدوال)

* يمكن أن تبدأ أسماء المتغيرات والدوال بحرف عربي أو لاتيني أو شرطة سفلية (`_`).
* يمكن أن تحتوي في بقية الاسم على أرقام غربية أو عربية أو فارسية، بالإضافة إلى التشكيل والتطويل.
* يُنصح باستخدام أسلوب `snake_case` العربي الواضح مثل: `مجموع_الدرجات`، `حساب_الضريبة`.

## 4. الفواصل والتنسيق الآلي

* **الفاصلة المنقوطة (`؛` أو `;`):** اختيارية في نهاية الأسطر؛ وتُستخدم فقط عند الجمع بين أكثر من أمر في سطر واحد.
* **الفاصلة (`،` أو `,`):** كلاهما مقبول للفصل بين عناصر القوائم ومعاملات الدوال.
* **المسافات البادئة:** 4 مسافات لكل مستوى كتلة برمجية.
* **التنسيق والفحص الآلي:**
  ```sh
  lisan نسّق ملف.lsn
  lisan نسّق --فحص ملف.lsn
  ```
