# سياسة الإصدارات المرحلية ودليل الترقية — Releases & Upgrading

يوضح هذا المستند دورة الإصدارات المرحلية للغة البرمجة العربية **لسان (Lisan)** ومعايير الترقية الآمنة بين الإصدارات.

## 1. مسار الإصدارات المرحلية (Staged Releases)

تعتمد لسان الترقيم الدلالي (`MAJOR.MINOR.PATCH`) مع مراحل إصدار متدرجة للوسوم (`Git Tags`):

1. **إصدار تجريبي أولي (`vX.Y.Z-alpha.N`):** لتجربة الميزات الجديدة مبكراً؛ يُنشر تلقائياً كـ **Pre-release** على GitHub.
2. **إصدار تجريبي عام (`vX.Y.Z-beta.N`):** بعد تجميد الميزات الرئيسية؛ يُنشر كـ **Pre-release** لاختبار التكامل والأمثلة.
3. **مرشّح للإصدار (`vX.Y.Z-rc.N`):** نسخة مطابقة للإصدار النهائي مخصصة للتحقق الأخير عبر المنصات الثلاث (Linux وmacOS وWindows).
4. **الإصدار المستقر (`vX.Y.Z`):** يُنشر كإصدار نهائي بعد نجاح كافة بوابات الجودة.

## 2. قائمة التحقق قبل أي إصدار (Release Checklist)

- نجاح سير عمل `Rust CI` (`cargo test --all-targets`) على المنصات الثلاث (`ubuntu-latest` و`macos-latest` و`windows-latest`).
- تحديث رقم الإصدار في `Cargo.toml` ونقل البنود من قسم `[Unreleased]` في `CHANGELOG.md` إلى قسم الإصدار الجديد مع تاريخه.
- التحقق من جاهزية البيئة والأدوات عبر `lisan doctor`.
- دفع الوسم (`git tag vX.Y.Z && git push origin vX.Y.Z`) ليعمل `.github/workflows/release.yml` تلقائياً ويبني حزم Linux (x86_64/ARM64) وWindows وmacOS مع ملفات التحقق `.sha256`.

## 3. ملاحظات الترقية بين الإصدارات (Upgrade Notes)

### الترقية من `0.6.0` إلى `0.8.0`
- أُضيف مسار الترجمة الأصلي (`--native` عبر LLVM/Clang) كمسار مستقل عن `--build` (الذي بقي للتوافق ويضمّ المفسّر).
- يتطلب `--native` توفر `clang` في `PATH` أو عبر متغير البيئة `CC`.

### الترقية من `0.8.0` إلى `0.9.1`
- أصبحت الفاصلة المنقوطة `؛` اختيارية في نهاية الأسطر مع بقاء الكود القديم الذي يستخدم `؛` متوافقاً بالكامل.
- أُضيفت بنى `حاول`/`التقط`/`أخيراً` و`اختر`/`حالة`/`افتراضي` ودوال JSON والعشوائية.

### الترقية من `0.9.1` إلى `1.0.0`
- دُعمت الأرقام العربية (`٠-٩`) والفارسية (`۰-۹`) إلى جانب اللاتينية (`0-9`) مع تطبيع الكلمات المفتاحية العربية.
- القوائم والقواميس أصبحت بدلالات مرجعية (Reference Semantics)؛ استخدم `.نسخ()` عند الحاجة لنسخة مستقلة.
- أُضيفت أدوات المطور المدمجة: `lisan --lsp`، `lisan نسّق`، `lisan اختبار`، `lisan حزمة`، و`lisan استوديو`.

### الترقية إلى ما بعد `1.0.0` (`Unreleased` ← الإصدار القادم)
- يدعم `--native` الآن تمرير وإرجاع النصوص والقوائم الرقمية في دوال المستخدم، مع إدارة ذاكرة ساحية (`@lisan_alloc`/`@lisan_free_all`) تمنع تسرب الذاكرة وإرجاع مؤشرات مكدس معلّقة.
- أُضيف أمر فحص البيئة الموحّد `lisan doctor` (أو `--doctor` / `فحص-البيئة`) وتوحيد امتداد `.exe` تلقائياً على Windows واحترام متغير `CC`.
- لا توجد تغييرات كاسرة (Breaking Changes) مقارنة بالإصدار `1.0.0`.
