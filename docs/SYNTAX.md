# قواعد لسان (مسودة تنفيذية)

## القيم والأرقام

- الأعداد اللاتينية فقط: `0`, `18`, `3.14`. غير مسموح `١٨` أو `۳` أو `٢٫٥`.
- القيم المنطقية: `صحيح` و`خطأ`؛ والقيمة الخالية `لاشيء`.
- النصوص: `"مرحبا"` مع هروب `\n` و`\t` و`\"` و`\\`.
- القوائم: `[1, 2, "نص"]`، والقواميس: `{"اسم": "سلمى", "العمر": 25}`.

## بناء البرنامج

```text
ليكن س = 10؛
متغير ن = 20؛
إذا (س < ن) { اطبع("نعم")؛ } وإلا { اطبع("لا")؛ }
بينما (س < 15) { س = س + 1؛ }
لكل (عنصر في [1, 2, 3]) { اطبع(عنصر)؛ }
دالة جمع(أ, ب) { أرجع أ + ب؛ }
اطبع(جمع(3, 5))؛
دع شخص = {"الاسم": "منى"}؛
شخص["العمر"] = 25؛
اطبع(شخص["الاسم"])؛
استورد "وحدة.lsn"؛
```

تُقبل `دع` و`ليكن` و`متغير` لتعريف متغير قابل للتغيير. `طالما` و`بينما` مترادفتان. الفهرسة تبدأ من الصفر. لا يدعم الإسناد المباشر سوى `متغير[مفتاح] = قيمة`، ولا يمكن الإسناد إلى فهرسة متداخلة.

## إنهاء التعليمات والفواصل (0.9.1)

الفاصلة المنقوطة `؛` أو `;` **اختيارية تماماً** عند نهاية السطر، تماماً كبايثون وجو وكوتلن:
- يمكن كتابة كل تعليمة في سطر مستقل دون أي فواصل.
- تلزم الفاصلة `؛` فقط إذا أردت كتابة عدة تعليمات على نفس السطر: `ليكن أ = 1؛ ليكن ب = 2`.

```text
ليكن اسم = "سارة"
ليكن درجات = [90, 85, 95]
إذا (مجموع(درجات) > 250) {
    اطبع("تهانينا يا " + اسم)
}
```

## مصحح الأخطاء الذكي والاقتراحات (0.9.1)

تتضمن لسان نظام تشخيص واقتراحات ذكي يساعد المبرمج والمبتدئ فوراً عند وقوع خطأ إملائي أو نسيان اسم:
- **اقتراح أسماء المتغيرات القريبة:** عند كتابة `النتيجه` بدلاً من `النتيجة`، تُظهر اللغة: `متغير غير معرّف: 'النتيجه' (هل تقصد 'النتيجة'؟)`.
- **اقتراح أسماء الدوال القياسية:** عند كتابة `اطببع` أو `مجمموع`، يقترح المصحح: `دالة غير معرّفة: 'اطببع' (هل تقصد 'اطبع'؟)`.
- **اقتراح مفاتيح القواميس:** عند طلب مفتاح غير موجود في قاموس `طالب["الاسمم"]`، يقترح: `المفتاح 'الاسمم' غير موجود في القاموس (هل تقصد 'الاسم'؟)`.

## المكتبة القياسية

- الأرقام: `مطلق(س)`, `جذر(س)`, `قرّب(س)`, `أدنى(س، ص)`, `أعلى(س، ص)`, `أرضية(س)`, `سقف(س)`, `قوة(س، أس)`.
- النصوص: `نظّف(نص)`, `اقتطع(نص، بداية، نهاية)`, `قسّم(نص، فاصل)`, `ادمج(قائمة، فاصل)`, `استبدل(نص، قديم، جديد)`, `يبدأ_ب(نص، بادئة)`, `ينتهي_ب(نص، لاحقة)`, `كرر(نص، مرات)`, `أحرف_كبيرة(نص)`, `أحرف_صغيرة(نص)`.
- القوائم: `مدى(نهاية)` أو `مدى(بداية، نهاية، خطوة)`, `أضف(قائمة، قيمة)`, `احذف(قائمة، فهرس)`, `عكس(قائمة)`, `فرز(قائمة)`, `مجموع(قائمة)`, `متوسط(قائمة)`, `ابحث(قائمة_أو_نص، عنصر)`.
- القواميس: `مفاتيح(قاموس)`, `قيم(قاموس)`, `احذف(قاموس، مفتاح)`, `يحتوي(قاموس، مفتاح)`.
- الملفات والمدخلات: `اقرأ_ملف(مسار)`, `اكتب_ملف(مسار، نص)`, `ألحق_ملف(مسار، نص)`, `ملف_موجود(مسار)`, `ادخل()`.
- عامة والنظام: `طول(شيء)`, `نوع(شيء)`, `نص(شيء)`, `عدد(نص)`, `عدد_صحيح(س)`, `الآن()`.

دالة `أضف` ودالة `احذف` تعيدان قيمًا جديدة، في حين أن `قاموس["مفتاح"] = قيمة` يعدّل المتغير الموجود.

## التحكم في الحلقات (0.6.0)

داخل `بينما` أو `لكل` يمكن استخدام `توقف؛` للخروج من الحلقة الأقرب، أو `تابع؛` للانتقال إلى الدورة التالية. يُرفض استخدامهما خارج الحلقات، كما يُرفض `أرجع؛` خارج الدالة.

```text
لكل (ن في مدى(0، 10)) {
    إذا (ن == 2) { تابع؛ }
    إذا (ن == 6) { توقف؛ }
    اطبع(ن)؛
}
```

## معالجة الاستثناءات والأخطاء (0.9.0)

توفر لسان بنية `حاول` و`التقط` و`أخيرًا` لاعتراض ومعالجة الأخطاء أثناء التشغيل، بالإضافة إلى أمر `ارمِ` لإطلاق استثناء مخصص:

```text
حاول {
    ليكن رصيد = -10؛
    إذا (رصيد < 0) {
        ارمِ "لا يمكن أن يكون الرصيد سالباً"؛
    }
} التقط (خطأ) {
    اطبع("تم اعتراض استثناء: " + خطأ)؛
} أخيرًا {
    اطبع("اكتملت المعالجة")؛
}
```

## بنية الاختيار والمطابقة (0.9.0)

تدعم لسان بنية `اختر` لتفريع المسارات بحسب قيمة تعبير معين على غرار `match` أو `switch`، مع دعم خيار `افتراضي`:

```text
اختر (الحالة) {
    حالة 200: {
        اطبع("نجاح")؛
    }
    حالة 404: {
        اطبع("غير موجود")؛
    }
    افتراضي: {
        اطبع("حالة غير معروفة")؛
    }
}
```

## العمليات العددية (0.6.0)

- الأرقام اللاتينية `0-9`، وتُقبل الكتابة العلمية مثل `1e3` أو `2.5E-2`.
- `**` للأسّ وهو يميني التجميع: `2 ** 3 ** 2` تساوي `512`، و`-2 ** 2` تساوي `-4`.
- الأخطاء العددية، مثل النتائج غير المنتهية أو الجذر العددي غير الصالح، تُوقف التنفيذ برسالة واضحة.
- `مدى(بداية، نهاية، خطوة)` يدعم الخطوات الموجبة والسالبة، مثل `مدى(5، 0، -2)`.
- `تحقق(شرط)` و`تحقق_يساوي(فعلي، متوقع)` تُنتجان خطأً عند فشل الاختبار. يمكن تشغيل ملف اختبارات عبر `lisan --test ملف.lsn`، وينتهي البرنامج بحالة خروج غير صفرية عند الفشل.
