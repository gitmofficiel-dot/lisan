📥 تحميل برنامج لسان لسطح المكتب (Lisan Desktop & CLI)

ثبّت مترجم واستوديو لسان 1.0 الأصلي على جهازك بضغطة زر للوصول الكامل إلى نظام الملفات، قواعد البيانات المستديمة، الترجمة الأصلية عبر LLVM/Clang، وبرمجة العتاد المباشرة.

🐧 لينكس (Ubuntu / Debian / Fedora) نظامك الحالي
curl -sSf https://raw.githubusercontent.com/gitmofficiel-dot/lisan/main/install.sh | sh
📦 حزمة Ubuntu/Debian (.deb) 🗜️ أرشيف Linux x64 (.tar.gz)
🪟 ويندوز (Windows 10 / 11 x64) نظامك الحالي
irm https://raw.githubusercontent.com/gitmofficiel-dot/lisan/main/install.ps1 | iex
⚡ الملف التنفيذي المباشر (.exe) 🗜️ حزمة Windows الكاملة (.zip)
🍎 ماك (macOS Apple Silicon & Intel) نظامك الحالي
curl -sSf https://raw.githubusercontent.com/gitmofficiel-dot/lisan/main/install.sh | sh
🍏 Apple Silicon M1–M4 (.app / arm64) 💻 macOS Intel (.app / x86_64)
