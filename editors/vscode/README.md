# إضافة محرّر Visual Studio Code للغة البرمجة العربية **لسان (Lisan)** — الإصدار 1.2.0

بيئة تطوير متكاملة (IDE) وعصرية للغة البرمجة العربية الخالصة **لسان** (`.lsn` / `.lisan`) داخل **Visual Studio Code**، مصمّمة لتعمل **فوراً دون أي اعتماديات npm خارجية** (Zero-Dependency).

---

## المزايا الرئيسية | Key Features

- **خادم لغة LSP مدمج (`lisan --lsp`)**: تشخيص فوري للأخطاء، فحص العربية الخالصة، إكمال تلقائي ذكي، وتوثيق عربي عند التحويم (Hover).
- **مصحح أخطاء حقيقي DAP (`lisan --dap`)**: نقاط توقف (Breakpoints)، تتبّع خطوة بخطوة (`F10`)، فحص المتغيرات الحية، وتقييم التعابير العربية مباشرة من لوحة التصحيح (`F5`).
- **معاينة حية للويب وتطبيقات الهاتف والرسوم (`Ctrl+Alt+P`)**: تشغيل ملف لسان وعرض HTML / SVG / PWA مباشرة داخل لوحة Webview في VS Code مع تحديث تلقائي عند الحفظ.
- **ترجمة ورفع للمتحكمات الدقيقة (MCU)**: ترجمة مباشرة إلى **Arduino / ESP32 / STM32 / Raspberry Pi / Pico (RP2040)** والرفع عبر `arduino-cli` أو `mpremote`.
- **الترجمة لبايثون وجافاسكربت**: توليد ملفات Python 3 (`.py`) و ES2022 JavaScript (`.js`) بضغطة زر.
- **معالج إنشاء مشاريع عربية جديدة**: قوالب جاهزة لمشاريع (`ويب` / `تطبيق_هاتف` / `ذكاء_اصطناعي` / `متحكم` / `أداة_نظام`) مع `lisan.json` و`.vscode/launch.json`.
- **23 مقطعاً جاهزاً (Snippets)** وتلوين نحوي متقدم يدعم الأنواع التدريجية، السلاسل المنسّقة `ن"..."`، والأرقام العربية `٠-٩`.

## التثبيت | Installation

### 1. تثبيت حزمة الإضافة (VSIX)
```bash
code --install-extension lisan-arabic-lang-1.2.0.vsix
```

### 2. التشغيل المباشر من المجلد (بدون `npm install`)
يمكنك نسخ أو ربط المجلد `editors/vscode` مباشرة داخل مجلد إضافات VS Code، أو فتحه والضغط على `F5` لتشغيل Extension Development Host:
```bash
# Linux / macOS
ln -s "$(pwd)/editors/vscode" ~/.vscode/extensions/lisan-lang.lisan-arabic-lang-1.2.0
```

تأكد من وجود الأمر التنفيذي `lisan` في مسار النظام (`PATH`)، أو حدّد مساره من الإعدادات:
```json
{
  "lisan.executablePath": "/path/to/lisan",
  "lisan.lsp.enabled": true,
  "lisan.arabicOnlyStrict": true,
  "lisan.mcuDefaultTarget": "esp32",
  "lisan.serialPort": "/dev/ttyUSB0"
}
```

## تصحيح الأخطاء (Debugging with DAP)

1. افتح أي ملف `.lsn` وضع نقطة توقف (Breakpoint) بالنقر بجانب رقم السطر.
2. اضغط `F5` (أو أنشئ `.vscode/launch.json` بالتكوين التالي):
```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "lisan",
      "request": "launch",
      "name": "تصحيح ملف لسان الحالي",
      "program": "${file}",
      "stopOnEntry": false
    }
  ]
}
```
3. استخدم شريط التصحيح للتنقل خطوة بخطوة (`F10`)، المتابعة (`F5`)، مراقبة المتغيرات في لوحة **Variables**، وتقييم التعابير العربية في **Debug Console**.

## رفع الشيفرة إلى المتحكمات الدقيقة | MCU Upload

- **Arduino / ESP32 / STM32**: يتطلب تثبيت [`arduino-cli`](https://arduino.github.io/arduino-cli/) وحزمة اللوحة المستهدفة.
- **Raspberry Pi Pico / Pico W (RP2040)**: يتطلب تثبيت [`mpremote`](https://docs.micropython.org/en/latest/reference/mpremote.html)؛ يقوم الأمر برفع الملف إلى `:main.py` وإعادة تشغيل اللوحة تلقائياً.
- اضبط المنفذ التسلسلي الافتراضي في `lisan.serialPort` (مثل `/dev/ttyUSB0` أو `/dev/ttyACM0` أو `COM3`).

## ربط خادم MCP مع وكلاء الذكاء الاصطناعي | MCP Setup

إذا كان إصدار `lisan` لديك يوفّر وضع خادم بروتوكول سياق النموذج (`lisan --mcp`)، يمكنك ربطه داخل إعدادات MCP في VS Code أو محررات الذكاء الاصطناعي (`.vscode/mcp.json`):
```json
{
  "servers": {
    "lisan": {
      "type": "stdio",
      "command": "lisan",
      "args": ["--mcp"]
    }
  }
}
```
يتيح ذلك لوكلاء الذكاء الاصطناعي فحص شيفرة لسان العربية وتشغيلها وتنسيقها وترجمتها للمنصات والعتاد مباشرةً.
