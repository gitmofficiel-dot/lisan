# إضافة محرّر Visual Studio Code للغة لسان

توفر هذه الإضافة دعماً متكاملاً للغة البرمجة العربية **لسان** (`.lsn`):
- **التمييز النحوي (Syntax Highlighting):** تلوين دقيق لكافة الكلمات المفتاحية، الدوال القياسية، هياكل البيانات، وسلاسل النصوص المنسقة `f-strings`.
- **المقاطع الجاهزة (Snippets):** مقاطع سريعة لإنشاء الدوال، الشروط، الحلقات، الأصناف، والاستثناءات.
- **تنسيق الشيفرة التلقائي (Formatting):** دعم اختصار `Shift + Alt + F` لتنسيق الكود مباشرة عبر `lisan --fmt`.
- **خادم لغة LSP مدمج:** يتصل مع خادم لسان (`lisan --lsp`) ليوفّر:
  - تشخيص الأخطاء فورياً مع أرقام الأسطر والأعمدة باللغة العربية الفصحى.
  - إكمال تلقائي ذكي (Autocompletion) للكلمات المفتاحية والدوال القياسية.
  - توثيق عند التحويم (Hover Documentation) يشرح دور كل دالة وكلمة مفتاحية.

## التشغيل والتطوير

1. تأكد من توفر أمر `lisan` في مسار النظام (PATH).
2. افتح مجلد `editors/vscode` في VS Code، واضغط `F5` لتشغيل Extension Development Host.
